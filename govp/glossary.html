Glossary

Precise terms used by the GOVP-1 specification and verifier.

Asset
The exact bytes identified by the signed SHA-256 digest.
Canonical URI
The exact HTTPS publication identity signed into the record.
Core-valid
The record format, signature and GOVP-ID checks pass; asset and transport checks depend on supplied inputs.
Evidence URI
An issuer-declared location for the asset or statement. It remains untrusted data.
GOVP-ID
A content-derived identifier computed from asset type, asset ID and asset SHA-256.
Native verifier
The implementation that validates an upstream evidence object's own format, signatures and trust semantics.
Profile
Additional governed rules layered on the frozen core.
Signing input
The exact domain-separated UTF-8 bytes verified by Ed25519.
Upstream evidence object
An exact signed message, receipt, envelope, attestation, bundle or other object supplied as the GOVP asset.
Vector
A fixture with expected parsing, hashes, validation decisions and warnings.
GOVP

Open protocol for independently verifiable digital artifacts.
