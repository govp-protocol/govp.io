GOVP 0.1.11

Governance

A conservative change process for a portable format whose value depends on deterministic behavior.

Frozen core

GOVP-1 signing input, field semantics, identifier derivation and existing conformance vectors are frozen. A verifier patch may reject inputs that were always invalid, but it must not change the signing bytes of a valid GOVP-1 record.

Change classes

  • Editorial: clarification with no behavioral change.
  • Registry: a reviewed addition such as an asset type code.
  • Profile: additional rules layered on the core.
  • Protocol: incompatible behavior requiring a new version.

Decision record

Proposals and decisions are public in the canonical repository. Changes require tests, conformance impact analysis, security review and clear migration guidance. Brilyetz Holding S.L., operating through its Gemacode brand, is the current project steward.
