# Contributing

Use the canonical [`govp`](https://github.com/govp-protocol/govp) repository
for changes to GOVP-1 signed bytes, identifiers, schemas, conformance vectors
or the reference verifier.

Use this repository for rendered documentation, accessibility, the browser
verifier and Cloudflare delivery. A website change must not silently alter a
normative artifact. Run `npm test` before proposing it.

Do not submit secrets, signing keys, customer data, personal records, private
evidence or unapproved real-world examples. Security reports follow
[`SECURITY.md`](SECURITY.md).
